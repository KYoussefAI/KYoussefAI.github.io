# Youssef Khaloufi — Portfolio

A zero-dependency static portfolio built for GitHub Pages.

## Deploy

1. Replace the files in your `KYoussefAI.github.io` repository with the contents of this folder.
2. Keep `assets/Youssef_Khaloufi_CV.pdf` or replace it with your latest CV using the same filename.
3. Commit and push to the `main` branch.
4. GitHub Pages will serve it at `https://kyoussefai.github.io/`.

## Edit projects later

- Main experience: search for `Mobility Control Tower` in `index.html`.
- Featured project: search for `Amazon Reviews`.
- Smaller projects are under the `earlier-grid` block.
- Skills are under the `stack-grid` block.

The site uses only HTML, CSS and a few lines of JavaScript. No build step is required.
