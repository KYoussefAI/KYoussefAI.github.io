## Selected engineering work

### [Mobility Control Tower](https://github.com/KYoussefAI/Mobility_Control_Tower)
A public-transport data platform combining scheduled GTFS data with GTFS-Realtime observations. It preserves source history, validates and models data using Python and dbt, orchestrates pipelines with Airflow, and supports reliability analysis in DuckDB. Unobserved service is treated as *unknown* rather than incorrectly inferred as delayed or cancelled.

### [Amazon Reviews Streaming Sentiment Pipeline](https://github.com/KYoussefAI/amazon-reviews-streaming-pipeline)
A batch-and-streaming system for sentiment analysis, featuring Spark ML model evaluation, Kafka-based event flow, Spark Structured Streaming, MongoDB persistence, and an analytics interface.

### [Job Data Pipeline — France](https://github.com/KYoussefAI/job-data-pipeline-france)
An end-to-end pipeline collecting data-related job listings through the Adzuna API, preserving ingestion history, transforming records into Parquet, and serving PostgreSQL-backed analytics. The project examines the limitations of interpreting API-collected listings as complete historical market data.
